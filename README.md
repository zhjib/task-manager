# 📋 智能任务管理系统（Node.js + React + Supabase + Vercel）

一个中文界面的任务管理 Web 应用：Node.js 后端 + React 前端 + Supabase（PostgreSQL）云端数据库，可部署到 Vercel 获得公网访问。

## 功能

- 输入框 + 优先级下拉（高 / 中 / 低）添加任务
- 任务列表按创建时间**倒序**显示（最新在前）
- 每条任务显示：标题、优先级标签、完成状态
- 每条任务两个按钮：切换「完成 / 未完成」、删除
- 已完成任务文字加**删除线**、颜色变淡
- 顶部按优先级筛选：全部 / 高 / 中 / 低
- 关掉浏览器再打开，数据还在（Supabase 云端持久化）

## 技术栈

| 层 | 技术 |
|---|---|
| 前端 | React 18 + Vite（构建到 `dist/`） |
| 后端 | Node.js + Express（REST API，`@supabase/supabase-js` 访问数据库） |

## 一、创建 Supabase 数据库

### 1.1 新建项目

1. 登录 [https://supabase.com](https://supabase.com)，点 **New Project**
2. Name：`task-manager`；Database Password：自己设强密码（留存）
3. Region：选 **Southeast Asia (Singapore)**（国内访问最快）
4. 点 Create，等 1~2 分钟变 Active

### 1.2 建 tasks 表

左侧 **SQL Editor → New query**，粘贴执行：

```sql
create table if not exists tasks (
  id bigint generated by default as identity primary key,
  title text not null,
  priority text not null default '中' check (priority in ('高', '中', '低')),
  completed boolean not null default false,
  created_at timestamptz not null default now()
);
```

看到 `Success. No rows returned` 即成功。

| 字段 | 类型 | 作用 |
|---|---|---|
| id | bigint 自增主键 | 任务唯一编号 |
| title | text | 任务标题 |
| priority | text（高/中/低） | 优先级 |
| completed | boolean 默认 false | 是否完成 |
| created_at | timestamptz 默认当前时间 | 创建时间（倒序用） |

### 1.3 打开 RLS 访问策略（关键，不做写不进数据）

继续在 SQL Editor 执行：

```sql
alter table tasks enable row level security;

create policy "Allow anon read" on tasks for select using (true);
create policy "Allow anon insert" on tasks for insert with check (true);
create policy "Allow anon update" on tasks for update using (true) with check (true);
create policy "Allow anon delete" on tasks for delete using (true);
```

> 提示 policy already exists 不影响。教学演示用"任何人可读写"，正式项目应改为登录用户隔离。

### 1.4 拿连接凭据

**Project Settings → API Keys**（或顶部 Connect → App Frameworks）复制：

| 凭据 | 长什么样 |
|---|---|
| Project URL | `https://xxxxxxxx.supabase.co` |
| Publishable key | `sb_publishable_xxxxxxxx` |

⚠️ 以 `sb_publishable_` 开头的新 key 才是要用的；`sb_secret_...` 是保密密钥，绝不外传、绝不进 GitHub。

## 二、本地运行

```bash
cp .env.example .env    # 把上面两个值填进 .env
npm install
npm run dev             # React(5173) + Express(3000) 同时启动，浏览器打开 http://localhost:5173
```

生产模式模拟：

```bash

npm start               # http://localhost:3000
```

`.env` 内容：

```
SUPABASE_URL=https://你的项目ID.supabase.co
SUPABASE_ANON_KEY=sb_publishable_你的key
```

## 三、代码上传 GitHub

1. GitHub 右上角 **+ → New repository**：Repository name `task-manager`，选 **Public**（Vercel 免费版需公开仓库），**不要**勾 Add a README；点 Create，复制仓库地址。
2. 生成 PAT（Personal Access Token）：GitHub → 头像 → **Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token**，勾选 `repo` 权限，复制保存（只显示一次）。
3. 本地执行（把地址和 PAT 换成你的）：

```bash
cd task-manager
git init
git add .
git commit -m "init: 智能任务管理系统"
git remote add origin https://github.com/你的用户名/task-manager.git
git branch -M main
git push -u origin main
```

> 推送时提示密码：用户名填 GitHub 用户名，"密码"处粘贴 PAT（GitHub 已不支持账号密码推送）。

**务必确认 `.env` 没有进入仓库**（本项目 `.gitignore` 已包含 `.env`）。

## 四、Vercel 部署上线

### 4.1 导入仓库

1. 登录 [https://vercel.com](https://vercel.com)，**Add New → Project**
2. 在 Import Git Repository 列表找到 `task-manager`，点 **Import**
3. Vercel 自动识别 Node.js 项目（`vercel.json` 已配置好 React 构建 + API 函数），构建配置不用改

### 4.2 配置环境变量（重点）

Import 页面的 **Environment Variables** 逐条添加：

| Name | Value |
|---|---|
| `SUPABASE_URL` | 你的 Project URL |
| `SUPABASE_ANON_KEY` | 你的 Publishable key |
| `NODE_ENV` | `production` |

⚠️ 变量名不要改：`SUPABASE_ANON_KEY` 是代码里写死的，值用 `sb_publishable_...` 即可，SDK 两种格式都认。

### 4.3 点 Deploy

1~3 分钟后得到域名，形如 `https://task-manager-xxx.vercel.app`，打开即上线。

### 4.4 绑定自定义域名

1. Vercel 项目 → **Settings → Domains → Add**，输入你的域名（姓名的拼音+序号.`rangzijigenghao.online`，如 `zhousan1.rangzijigenghao.online`）
2. 按 Vercel 提示到域名服务商添加 **两种** 记录：
   - **CNAME**：主机记录填域名前缀（如 `zhousan1`），记录值填 Vercel 给的 `cname.vercel-dns.com`
   - **TXT**（域名验证用）：按 Vercel 页面显示的主机记录/值原样添加
3. 回 Vercel 点 Verify / Refresh，生效后即可用自定义域名访问

## REST API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/tasks` | 任务列表（创建时间倒序）；`?priority=高/中/低` 筛选 |
| POST | `/api/tasks` | 添加任务，body `{ "title": "标题", "priority": "高" }` |
| PATCH | `/api/tasks/:id` | 切换完成状态，body `{ "completed": true }` |
| DELETE | `/api/tasks/:id` | 删除任务 |

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `new row violates row-level security policy` | RLS 策略没开全 | 重跑 1.3 的四条 policy SQL |
| `relation "tasks" does not exist` | 表没建成功 | 重跑 1.2 建表 SQL |
| `Permission denied` / 要求密码 | GitHub 不支持账号密码推送 | 使用 PAT 或 SSH key |
| 仓库误传 `.env` 和 key | — | 去 Supabase 轮换 key，删 `.env` 重新提交 |
| Vercel 部署失败 | 环境变量缺失/拼错 | 看 Deployments → Build Logs，改完 Redeploy |
| 本地有数据、线上没有 | 连的不是同一个 Supabase | 核对两边 `SUPABASE_URL` 项目 ID |
| 旧 anon key 提示弃用 | JWT 旧 key 将停用 | 换 `sb_publishable_...`，代码不用改 |
